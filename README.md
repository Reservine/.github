# Reservine GitHub configuration

This repository owns the public organization profile and the reviewable source
for Reservine's organization-level GitHub rulesets.

- `profile/README.md` renders on the organization's public Overview page.
- `rulesets/` documents the protected-branch policy applied through GitHub.

The product source repositories are private. Public product information lives
at [reservine.io](https://reservine.io/en).
Organization profile and GitHub governance for Reservine.
